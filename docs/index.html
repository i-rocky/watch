Why

On Linux and macOS, watch is the tool you reach for to re-run a command every few seconds and stare at the output. Windows never shipped it. This is GNU watch rebuilt for Windows — mirroring GNU flags and behavior where possible, so your muscle memory just works.

Feels like the real thing

Mirrors GNU watch flags and behavior where possible. watch -n 2 "dir" does exactly what you expect.

Alternate-screen TUI

Live updates in an alternate screen — no scrollback spam. Your terminal history stays clean when you quit.

Diff highlighting

Spot changes between runs with -d, or accumulate every change ever seen with --differences=permanent.

Screenshot capture

Press s while running to save a snapshot of the current output to --shotsdir.

Usage

watch -n 2 "dir"
watch -d "date /t"
watch --differences=permanent "powershell -c Get-Date"
watch -t -w -x "echo hello"

Common flags

FlagWhat it does
-n, --interval <secs>refresh interval (default 2.0s)
-d, --differences[=permanent]highlight changes; permanent keeps every change highlighted
-t, --no-titlehide header
-w, --no-wraptruncate long lines (alias: --no-linewrap)
-x, --execexecute without a shell
-f, --followappend output instead of clearing
-p, --preciseschedule runs on a fixed cadence instead of after each run
-b, --beepbeep when the command exits non-zero
-c, --color / -C, --no-colorforce ANSI color handling on/off
-e, --errexitfreeze on non-zero exit, quit after a key press
-g, --chgexitexit when the output changes
-q, --equexit <cycles>exit when output is unchanged for N cycles
-r, --no-rerundo not rerun the command on key-triggered refresh
-s, --shotsdir <dir>directory for screenshots taken with the s key

Keys while running

KeyAction
q / Ctrl+Cquit
spacetrigger immediate refresh
